# Project 1: Deterministic Rule-Based AI Chatbot 🤖

## 📌 Project Overview
This project is part of the **DecodeLabs Industrial Training Kit (Batch 2026)** Foundation Phase. It implements a **White Box Model** chatbot using pure deterministic logic, demonstrating a complete **Input-Process-Output (IPO)** architecture with zero hallucination risk. 

Instead of probabilistic machine learning, this system utilizes strict control flow and explicit `if-else` decision-making logic gates to simulate human interaction and act as a foundational AI Guardrail.

## 🚀 Key Features
- **Continuous Feedback Loop:** Runs inside a persistent digital execution loop until an explicit exit command is received.
- **Input Sanitization & Normalization:** Phase 1 module that cleans raw user feed (handling case-insensitivity and whitespace stripping) to prevent logic breaks.
- **Intent Matching Engine:** Pure programmatic `if-else` logic skeleton that maps predefined inputs to hard-coded, safe responses.
- **Modern Graphical User Interface (GUI):** Built using Python's `tkinter` library, featuring a custom dark/cyan theme inspired by industrial engineering layouts.

## 🛠️ Tech Stack & Skills Demonstrated
- **Language:** Python 3
- **GUI Library:** Tkinter (ScrolledText module)
- **Core Skills:** Control Flow, Logic Gates, Input Normalization, Rule-Based AI Guardrails, Deterministic System Design.
